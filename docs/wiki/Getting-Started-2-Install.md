# 2. Install via HACS

BavarianData is installed through [HACS](https://hacs.xyz/) as a custom
repository.

## Requirements

- Home Assistant **2026.3** or newer.
- HACS installed.

## Steps

1. In HACS, open **Custom repositories**.
2. Add this repository — `https://github.com/JustChr/BavarianData` — with
   category **Integration**.
3. Install **BavarianData: Connect Home Assistant to BMW CarData**.
4. **Restart Home Assistant.**

> HACS users receive updates only from **GitHub releases**, not from every push
> to `main`. Track the releases page for new versions.
