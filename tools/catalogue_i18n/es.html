CATÁLOGO DE DATOS TELEMÁTICOS DE BMW CARDATA.

BMW CarData proporciona datos telemáticos relevantes que los vehículos envían a BMW Group, donde se guardan, al utilizar los servicios BMW ConnectedDrive. Entre estos datos se incluyen valores como el kilometraje. En este catálogo de datos telemáticos de BMW CarData se detallan todos los datos disponibles del vehículo relevantes para el uso de BMW CarData, clasificados en diferentes categorías. La cantidad y el tipo de datos telemáticos pueden variar en función del tipo de vehículo, del sistema de propulsión, del modelo, del año de construcción y del equipamiento opcional disponible.

Para obtener una versión interactiva, visite nuestro sitio en línea catálogo de datos telemáticos.
