CATÁLOGO DE DADOS TELEMÁTICOS BMW CARDATA.

O BMW CarData coloca à disposição dados telemáticos importantes que os veículos transmitem ao BMW Group, através dos serviços BMW ConnectedDrive, para efeitos de armazenamento. Esses dados incluem valores como, por exemplo, a quilometragem. Este catálogo de dados telemáticos da aplicação BMW CarData esclarece todos os dados fundamentais do veículo disponíveis para a utilização da aplicação BMW CarData – subdivididos em diversas categorias. A quantidade e o tipo de dados telemáticos variam consoante o tipo de veículo, o tipo de acionamento, o modelo, o ano de construção e o equipamento opcional existente.

Para uma versão interativa, por favor visite o nosso site catálogo de dados telemáticos.
